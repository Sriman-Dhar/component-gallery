Won over Instrument (dark, mono, dense) and Editorial. Instrument was rejected twice over: it intimidates a non-quant ops buyer, AND it was the same family as the previously logged direction.

What worked: the ledger-as-hero reframed a trust claim as verifiable evidence; one accent held across CTA, focus and the balance strip; hierarchy built from weight and position kept the type system small.

What I would change: the shipped type scale drifted to six sizes against the brief's four. The People-to-Gross gutter is wider than it needs to be. Reduced-motion path is implemented but was never verified with the OS preference actually enabled.

Traps hit, worth remembering: (1) ui-ux-pro-max returned purple + ambient blobs + glassmorphism for a trust-first fintech brief — the brief has to outrank it. (2) 21st.dev Magic returned six heroes, max confidence 0.61, all slop for this brief; rejecting a registry result is a valid outcome. (3) Tailwind v4 silently ignores the v3 'rounded-[--var]' shorthand — measure computed radius, do not assume. (4) shadcn Button's focus ring composed to fully transparent; fix once at [data-slot=button] with an outline rather than per call site.
