## Mechanism

A multi-route site picks one signature object (here: a ledger, a running record
of real work) and gives every route exactly ONE transformation of it, plus a
shared masthead and close so the frame never drifts. The transformation changes
what each row carries and what the columns mean, not the family:

- capability -> row opens onto the artifacts that arrive with it
- price      -> itemised statement, figures in one tabular column
- product    -> columns whose fact rows share grid lines, read across
- history    -> dated record, the year as the loudest object
- beliefs    -> deliberate stillness, no rows at all

## Problem it solves

Multi-page sites drift: eight routes get eight openings and the same card grid
as every section's default, so the site reads as one template with different
nouns. Recolouring does not fix it, because the failure is structural.

## Why it works

A shared frame plus a per-route transformation separates the two things a
visitor judges independently. The frame answers "is this one company", which
wants sameness. The signature section answers "does this page know its own
job", which wants difference. Card grids fail both: they are neither
distinctive enough to be a signature nor specific enough to be a frame.

## Where it breaks

Needs a signature with real semantic range. If the object cannot honestly
become five different things, forcing it produces five contrived variations,
which is worse than a card grid. Test it by writing the transformation table
BEFORE building: if a route's cell cannot be filled, that route is not designed.

Also watch the replacement rut: swapping "card grid everywhere" for "hairline
rows everywhere" is a different default, not a system. At least two routes
should break the family outright (here the comparison wall and the manifesto).

## Transfer

Any product with a documentation site, a multi-surface admin, or a deck series.
The signature can be a timeline, a receipt, a diff, a map, a queue: anything
whose columns can mean different things while its shape stays recognisable.
