Mechanism: repetition of an identical element makes it read as 'safe' before it is read; the ledger under it changes state each page, so the reader feels the gap. Why it works: the eye compares the constant against the variable. Breaks: if the constant element is large or coloured like the truth layer. Transfer: dashboards (a green header over red rows), audit reports, changelogs.
