# Skills available in this repo

Design-capable skills for building components in this gallery. Invoke `lofistack-frontend-stack`
first for any UI work; it routes to the others below.

- brand — brand voice, visual identity, messaging frameworks, asset consistency
- design-intelligence — creative-direction and design-research layer; run before building or
  judging any interface
- design-system — token architecture, component specs, spacing/typography scales
- design-taste-frontend — anti-slop frontend skill for landing pages, portfolios, redesigns
- gsap-core — GSAP core API: tweens, easing, stagger, responsive/reduced-motion animation
- gsap-react — GSAP in React: useGSAP hook, refs, cleanup
- gsap-scrolltrigger — GSAP ScrollTrigger: scroll-linked animation, pinning, parallax
- gsap-timeline — GSAP timelines for sequencing animation
- lofistack-frontend-stack — master design pipeline and skill router for any design work
- threejs-webgl — Three.js / React Three Fiber, GLSL shaders, particles, 3D/WebGL scenes
- ui-styling — shadcn/ui, Tailwind CSS, accessible components, theming
- ui-ux-pro-max — UI/UX design intelligence: styles, palettes, font pairings, product types
